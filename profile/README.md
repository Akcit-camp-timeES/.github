# AKCIT Camp

### Preparação documental para licitações

Estamos desenvolvendo uma central para apoiar pequenas empresas de serviços técnicos na organização de comprovantes e na revisão de exigências de editais.

## MVP em desenvolvimento

- Organizar documentos com versões rastreáveis.
- Relacionar exigências do edital a trechos de documentos candidatos.
- Evidenciar divergências e informações que ainda faltam.
- Apoiar revisão humana, tarefas e checklist versionado.

## Princípios

- Cada sugestão deve apontar para documento, versão, página e trecho.
- Informação insuficiente permanece explícita; falta de evidência não prova incapacidade.
- A ferramenta apoia a revisão documental. Não confirma habilitação nem autenticidade.
- A demonstração usa dados sintéticos. Não envie documentos reais.
